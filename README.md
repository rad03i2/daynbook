# دفتر الدين | DaynBook

تطبيق أندرويد عربي لإدارة ديون الزبائن للمحال والبقالات، مصمم بأسلوب **Offline-First** للهاتف والتابلت مع حماية سحابية مشفرة عبر Google Drive.

> **الحالة الحالية:** المرحلة الأولى الأساسية منفذة، والمرحلة الثانية الخاصة بالنسخ السحابي المشفر أصبحت موجودة في الكود. بقي اختبار OAuth/WorkManager والاستعادة End-to-End على Android فعلي بعد توليد Android scaffold وإعداد بيانات Google Cloud.

## الفكرة

بدل الاعتماد على Excel للإدخال اليومي، يحفظ DaynBook البيانات مباشرة داخل التطبيق. لكل زبون صفحة مستقلة، رصيد حالي، وسجل كامل لحركات الدين والتسديد مع التاريخ والملاحظات.

## المبادئ الأساسية

- يعمل دون إنترنت.
- واجهة عربية RTL محسنة للهاتف والتابلت.
- تخزين SQLite محلي سريع وموثوق.
- كل مبلغ يُخزن كعدد صحيح بالدينار العراقي لتجنب أخطاء الكسور العشرية.
- سجل معاملات مستقل بدل تعديل الرصيد يدويًا.
- الرصيد يُحسب دائمًا من سجل الحركات.
- النسخ السحابي لا يعطل العمل المحلي إذا فشل الإنترنت أو Google.
- تشفير النسخ قبل مغادرة الجهاز.
- استعادة Transactional لتجنب قاعدة بيانات نصف مستعادة.
- تصدير PDF وExcel في المرحلة التالية دون استخدام Excel كقاعدة بيانات.

## التقنية

- Flutter / Dart
- SQLite عبر `sqflite`
- Google Sign-In 7.x
- Google Drive API v3 (`appDataFolder`)
- AES-256-GCM
- PBKDF2-HMAC-SHA256
- SHA-256 integrity checksum
- `flutter_secure_storage` لعبارة حماية النسخ التلقائي
- WorkManager للنسخ الدوري كل ساعة تقريبًا
- GitHub Actions للتحليل والاختبارات

## ما يعمل حاليًا

### الدفتر المحلي

- إنشاء زبون جديد.
- البحث بالاسم أو رقم الهاتف.
- فتح صفحة حساب الزبون.
- تسجيل دين جديد.
- تسجيل دفعة تسديد.
- حساب الرصيد تلقائيًا.
- عرض سجل الحركات بترتيب زمني.
- عرض إجمالي الديون.
- واجهة مختلفة تلقائيًا للهاتف والتابلت.
- قبول الأرقام العربية والإنجليزية في حقل المبلغ.

### الحماية السحابية — المرحلة 2

- Google Sign-In باستخدام API الحديث.
- طلب نطاق Google Drive الخاص ببيانات التطبيق فقط.
- Snapshot متسق من SQLite داخل Transaction.
- ضغط النسخة بـ gzip.
- تشفير النسخة بـ AES-256-GCM.
- اشتقاق المفتاح من عبارة حماية المستخدم.
- SHA-256 للتحقق من سلامة المحتوى.
- رفع النسخة إلى Google Drive `appDataFolder`.
- الاحتفاظ بأحدث 5 نسخ تلقائيًا.
- قائمة بالنسخ السحابية وتواريخها وأحجامها.
- زر نسخ فوري.
- استعادة أحدث نسخة أو نسخة محددة.
- استعادة قاعدة البيانات داخل Transaction واحدة.
- شاشة عربية لحالة Google والتشفير وآخر نسخة ناجحة.
- حفظ عبارة الحماية محليًا في Secure Storage لتشغيل النسخ الخلفي.
- جدولة نسخة كل ساعة تقريبًا عند توفر الإنترنت والبطارية والتخزين المناسب.

## أمن النسخ
