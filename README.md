# دفتر الدين | DaynBook

تطبيق أندرويد عربي لإدارة ديون الزبائن للمحال والبقالات، مصمم ليعمل بأسلوب **Offline-First** على الهاتف والتابلت مع نسخ احتياطي سحابي آمن في Google.

> **الحالة الحالية:** المرحلة الأولى قيد التنفيذ، والأساس المحلي أصبح موجودًا فعليًا في المستودع.

## الفكرة

بدل الاعتماد على Excel للإدخال اليومي، يحفظ DaynBook البيانات مباشرة داخل التطبيق. لكل زبون صفحة مستقلة، رصيد حالي، وسجل كامل لحركات الدين والتسديد مع التاريخ والملاحظات.

## المبادئ الأساسية

- يعمل دون إنترنت.
- واجهة عربية RTL محسنة للهاتف والتابلت.
- تخزين SQLite محلي سريع وموثوق.
- كل مبلغ يُخزن كعدد صحيح بالدينار العراقي لتجنب أخطاء الكسور العشرية.
- سجل معاملات مستقل بدل تعديل الرصيد يدويًا.
- الرصيد يُحسب دائمًا من سجل الحركات.
- نسخ احتياطي سحابي إلى Google في المرحلة الثانية.
- استعادة سهلة عند تبديل أو فقدان الجهاز.
- تصدير PDF وExcel لاحقًا دون استخدام Excel كقاعدة بيانات.

## التقنية

- Flutter / Dart
- SQLite عبر `sqflite`
- Google Sign-In + Google Drive API للنسخ الاحتياطي السحابي
- WorkManager للمهام الخلفية الدورية
- GitHub Actions لفحص التحليل والاختبارات

## نموذج البيانات

### Customers
- id
- name
- phone
- notes
- createdAt
- updatedAt

### Transactions
- id
- customerId
- type: debt / payment
- amount
- description
- notes
- createdAt

الرصيد الحالي لا يُكتب يدويًا، بل يُحسب من سجل الحركات:

`الرصيد = مجموع الديون - مجموع التسديدات`

## ما يعمل حاليًا

- إنشاء زبون جديد.
- البحث بالاسم أو رقم الهاتف.
- فتح صفحة حساب الزبون.
- تسجيل دين جديد.
- تسجيل دفعة تسديد.
- حساب الرصيد تلقائيًا.
- عرض سجل الحركات بترتيب زمني.
- عرض إجمالي الديون.
- واجهة مختلفة تلقائيًا للهاتف والتابلت.
- قبول الأرقام العربية والإنجليزية في حقل المبلغ.
